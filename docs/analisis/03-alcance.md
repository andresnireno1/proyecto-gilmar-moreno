Alcance del proyecto
Este proyecto aborda específicamente la desorientación académica y espacial de los
estudiantes de pregrado de la Corporación Universitaria Remington sede Medellín
mediante el desarrollo de una plataforma web centralizada. El alcance incluye la
integración de información académica estudiantil dispersa en múltiples canales
institucionales, la automatización del acceso personalizado a datos de matrícula,
horarios y asignación de aulas, y la implementación de un sistema de orientación
espacial interactivo para el campus universitario.
La solución contempla la centralización de información sobre asignaturas
matriculadas, horarios de clases, ubicación de salones y datos de contacto docente
en una interfaz web unificada. Incluye la generación automática de cronogramas
semanales personalizados y la implementación de mapas interactivos del campus
universitario con localización de facultades, laboratorios y servicios estudiantiles.
El proyecto se enfoca en estudiantes de pregrado de la Corporación Universitaria
Remington sede Medellín y contempla el desarrollo de una plataforma web responsiva
accesible desde dispositivos de escritorio, tablet y móvil. La implementación técnica
comprende desarrollo frontend, backend y base de datos para gestión de información
académica.
